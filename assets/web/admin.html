    外部访问

    经反向代理（带 X-Forwarded-For 等转发头，或 Host 是下面登记的域名）来的请求按外部访问处理：要登录才能看非公开项目和管理功能；刚发布的短链接和项目设置里勾了「公开阅读」的项目不登录也能只读。内网直连不受影响。密码和这些设置只能在内网修改。

    强制安全规则不可在后台关闭：隐藏路径、缓存与仓库目录、符号链接、凭据与SSH文件名、不支持的类型、含私钥的文本一律不收录。

    内网直连不设登录。能直接访问本端口的设备都能阅读和管理，请只在受信任的局域网内使用。所有操作只影响 Vinx Docs 自己的配置与阅读副本，不改动项目原文。

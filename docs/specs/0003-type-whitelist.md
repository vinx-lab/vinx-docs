# 项目收录的文件类型白名单

## 问题

登记目录里除了 Markdown 和 HTML，还有图片、JSON、脚本、表格等，全部被收录并列进导航，要看的文档被淹没。用 exclude 逐个排除类型太麻烦。维护者要的是：按项目设一个白名单，例如只收录 `.md`、`.html`。

## 方案

- 项目配置新增可选字段 `types`：允许收录的扩展名数组，如 `[".md", ".html"]`。缺省或空数组表示收录全部支持的类型，即现状，旧配置不需要迁移。
- 按**文件类型**限定，不按路径：目录里新写的 `.md` 照样自动出现。按路径的白名单仍不提供（原因见 [ADR 0002](../architecture-decisions/0002-exclude-only-scope.md)）。
- 过滤发生在收录阶段（`internal/build/walk.go`，排除规则之后、内容扫描之前）：不在白名单的文件不收录、不进索引和搜索、原始地址返回 404。强制安全规则和 exclude 照旧生效，白名单不会放宽它们。
- 校验（`ValidateProject`）：取值必须是程序支持的扩展名（`config.KindFor` 能识别的），统一小写、带点；项目首页是 Markdown，所以设了 `types` 就必须包含首页的扩展名，否则拒绝保存。
- 收录范围页：收录方式一行写明「只收录 .md、.html」；因类型被跳过的文件按扩展名汇总计数（如「.png 12、.json 30」），不逐条列出，避免上千行。Markdown 引用的图片若因此没收录，从这里能看出来。
- 管理后台：项目编辑区在排除规则旁加一组扩展名勾选框（按 Markdown、HTML、文本与代码、图片、表格分组），全不勾等于全部收录。保存走现有项目更新接口。
- 同步完成后立即生效，与改 exclude 相同；文件监听的增量刷新走同一收录逻辑。
- 同步修改相关文档与约定：新增 ADR 0004「收录范围可按文件类型限定」并把 0002 状态改为「已被 0004 取代」（按路径的白名单仍不采用）；更新 `AGENTS.md`、`README.md`、`docs/project-registration.md` 里「没有白名单」的表述。

## 取舍

- **按路径模式的白名单**（旧版 `include`）：新文件没命中规则就静默消失，而同步显示成功，这是 0002 移除它的原因。不选。
- **只从导航隐藏、照常收录**：图片和链接不受影响，但维护者要的是不收录。不选。
- **白名单自动带上被引用的图片**：要在收录阶段解析 Markdown/HTML 引用，复杂度高；需要图片时在白名单里勾上图片类型即可。不做。

## 验证

- 单元测试：`types` 校验（不支持的扩展名、不含首页扩展名时拒绝；大小写规范化；缺省等于全部）；设为 `[".md", ".html"]` 时收录结果只含这两类，exclude 和安全规则仍生效；范围页按扩展名汇总计数。
- HTTP：临时 `VINX_DOCS_HOME` 起服务，项目含 md/html/png/json，设 `types` 后同步，检查 `_sidebar.md` 只含 md/html，png、json 原始地址返回 404；去掉 `types` 后恢复。增量刷新：新建一个 `.md` 自动出现，新建 `.json` 不出现。
- 真实浏览器：管理后台勾选、保存、刷新后状态保留；阅读页导航只剩勾选的类型；范围页显示汇总。

## 结果

已实现。

- 配置：`internal/config/project.go` 新增 `types` 校验与规范化（`NormalizeType`、`Types`），以及后台勾选框用的分组 `TypeGroups`（与 `KindFor` 的扩展名集合一致，`.csv` 归入表格组）。`include` 报错不变。
- 收录：`internal/build/walk.go` 在 exclude、强制安全规则、未知类型判断之后，内容扫描之前按类型过滤；被跳过的文件按扩展名计数，不进排除条目，所以 exclude 未命中报告不受影响。范围页写明「只收录 …」并列出「因类型未收录」的计数。
- 接口：`/api/project/update` 接受 `types`，空数组表示删掉该字段（恢复全部收录）；`/api/config` 返回每个项目的 `types` 和全局 `typeGroups`。
- 后台：项目详情在排除规则下方按组列出扩展名勾选框，保存走原接口。
- 文档：新增 ADR 0004，0002 改为已被 0004 取代；更新 `AGENTS.md`、`README.md`、`docs/project-registration.md`。

验证：

- 单元测试：`types` 校验（不支持的扩展名、不含首页扩展名、非数组时拒绝；大小写规范化；缺省等于全部）；设为 `.md`、`.html` 时只收录这两类，exclude 和安全规则照旧，未命中的 exclude 照旧报告；范围页汇总计数；后台接口保存、规范化、清空恢复。`go test ./...` 全部通过。
- HTTP：临时家目录起服务，设 `types` 后 `_sidebar.md` 只含 md/html，png、json 原始地址 404；不含首页扩展名、不支持的扩展名均返回 400；新建 `.md` 经文件监听自动出现，新建 `.json` 不出现、计入范围页。
- 真实浏览器：后台勾选、保存、刷新后状态保留；阅读页导航只剩勾选类型；范围页显示汇总；全不勾保存后恢复全部收录。

未覆盖：没有扩展名的 `Makefile`、`Dockerfile` 无法写进 `types`，设了 `types` 就不收录，范围页记为「(无扩展名)」。

未验证：后台勾选框在深色模式和手机宽度下的样式。

# 0004 收录范围可按文件类型限定

状态：已采纳

## 背景

[0002](0002-exclude-only-scope.md) 规定收录范围只用黑名单。实际使用中，登记目录里除了 Markdown 和 HTML 还有图片、JSON、脚本、表格等，全部进导航后要看的文档被淹没；用 exclude 逐个排除类型又太麻烦。

## 决定

- 项目配置可选字段 `types`：允许收录的扩展名数组；缺省或空表示收录全部支持的类型。
- 只按文件类型限定，不按路径。按路径的白名单（旧版 `include`）仍不采用，原因同 0002：新文件没命中规则会静默消失，而同步显示成功。
- 过滤在 exclude 和强制安全规则之后、内容扫描之前；不在白名单的文件不收录、不进索引和搜索。
- 因类型未收录的文件在范围页按扩展名汇总计数，不逐条列出。

0002 的其余内容（整目录收录、exclude、未命中规则单独报告）继续有效。

## 影响

- 新写的同类型文档照样自动出现，不需要改配置。
- 设了 `types` 就必须包含首页的扩展名，否则拒绝保存。
- Markdown 引用的图片不会自动带上；需要时在白名单里勾上图片类型。

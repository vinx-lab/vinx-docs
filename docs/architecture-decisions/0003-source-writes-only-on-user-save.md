# 0003 只有用户在页面上保存时才改写源文件

状态：已采纳

## 背景

加入页面内编辑后，工具获得了写源文件的能力。源文件属于各个项目，一旦被构建、同步或 agent 批量改写，很难发现和恢复。

## 决定

- 只有用户在页面上主动保存时才写源文件。
- 保存前检查版本，不一致就拒绝，并返回当前内容供对比。
- 原子写入，写入前保留历史备份（每个文件最多 20 份），保留原来的 BOM 和换行符。
- 不自动提交 git。agent 改文档走它自己的工作目录，不经过本工具的写接口。

## 影响

- 编辑是单人、非协同的；两处同时编辑时后保存的一方会收到冲突提示。
- 写接口目前没有权限控制，能访问服务的设备都可以保存，见 README「安全模型」。
